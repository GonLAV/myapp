# Skill Advisor 🧭

**יועץ אסטרטגי שמלווה אותך בבניית מערכת ה-AI שלך.** עונה על השאלה "מה כדאי לי לבנות עכשיו?" — לא בניחוש, אלא מתוך הבנה מדויקת של המערכת שלך, מחקר של מה אחרים עשו, ואימות שההמלצה באמת מתאימה לך.

כלי **מלווה** — לא חד-פעמי. זוכר מה כבר בנית, מה נדחה ולמה, וממשיך מאיפה שעצרת.

---

## מה הוא עושה

- **"מה הלאה?"** — ממליץ את הצעד הבא לפי איפה שאתה במסע.
- **"עוד רעיונות"** — יוצא למחקר טרי ומביא מועמדים חדשים.
- **"יש לי רעיון — כדאי?"** — בוחן אותו כיועץ אסטרטגי מ-3 זוויות.
- **"עזור לי לבנות את X"** — מלווה את הבנייה צעד-אחר-צעד.

כל המלצה עוברת **אימות ב-3 עדשות** (התאמה אישית · היתכנות · ערך) לפני שהיא מגיעה אליך, עם ראש אפשרויות — מה מומלץ, מה לא, ואיך פסלנו.

---

## התקנה

העתק את תיקיית `skill-advisor/` (זו) לתיקיית הסקילים שלך:

```bash
cp -r skill-advisor ~/.claude/skills/
```

או התקן כפלאגין דרך מנהל הפלאגינים של Claude Code.

---

## הפעלה ראשונה (Onboarding)

בפעם הראשונה שתפעיל אותו, הוא יבנה לך בסיס:
1. יסרוק את ספריית הידע שלך (`master-library/` או מקבילה).
2. ישאל אם יש לך עוד מקורות (וולט / Notion / Drive).
3. יבנה לך שני קבצי מצב — **מודל-מערכת** ו**תוכנית-עבודה** — שהוא יזכור מהם בכל הפעלה הבאה.

> **לא צריך וולט או Notion.** הבסיס הוא ספריית הידע האישית שלך. מי שיש לו יותר — הסקיל שואל ומשתמש.

## עיקרון-על

**ממליץ, לא מחליט.** אתה מחזיק את ההגה — הוא עושה את העבודה הקשה (הבנה, מחקר, אימות) ומביא לך אפשרויות מדורגות. אתה מכריע.

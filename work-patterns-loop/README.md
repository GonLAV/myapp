# work-patterns-loop

## מה זה עושה

אוסף דפוסי עבודה-עם-AI אמיתיים של דניאל מתוך השיחות שלו ב-Claude Code (בכל פרויקט, לא רק כאן), ובונה מהם מדריך חי ("לנהל AI כמו דניאל מראד") — כל עיקרון עם ציטוט אמיתי מהשיחה שבה נצפה, לא טיפ גנרי. בהשראת מדריך "לנהל AI כמו עובד חדש" ששלהבת ורדי כתבה.

מעבר לזה — העיקרונות שמצטברים **חוזרים פנימה**: מוצעים לעדכון מסמכי הידע של אטלס (`agents/ready/atlas/master-library/`), כדי שאטלס עצמו ילמד ויתכוון לדניאל עם הזמן.

## למה ככה — לא בונה מנגנון מקביל

בריפו כבר יש שני מנגנונים שמזהים דפוסים: הכלל "קולט ידע" (ב-`~/.claude/CLAUDE.md`, תוך כדי שיחה) והסקיל `session-close` שמפעיל `learning-loop` (בסגירת שיחה). שניהם כבר עובדים היטב — אבל כל אחד מהם עוצר בגבול הפרויקט הבודד, ומייצר החלטה/כלל תמציתי, לא עיקרון מאומת עם עדות.

`work-patterns-loop` לא מחליף אותם ולא רץ במקביל אליהם — הוא **מרחיב** את שניהם בשתי הוספות בלבד (ר' `~/.claude/CLAUDE.md`, סעיף "קולט ידע"):
1. דפוס עבודה שאושר לשמירה נכתב גם לשורה במאגר מרכזי חוצה-פרויקטים.
2. בכל הפעלה של learning-loop — גם אוטומטית בסגירת שיחה, וגם כשדניאל מבקש זאת במפורש תוך כדי שיחה ("תלמד מהשיחה", "כל הכבוד, בוא נלמד מזה" וכו') — אם דפוס הצטבר 2+ פעמים עצמאיות, מוצע עדכון למדריך החי, ומשם — הצעה לעדכן את אטלס.

אין תזמון (cron) נפרד ואין סקריפט שרץ ברקע — כל הלוגיקה קורית בתוך שתי הנקודות שכבר קיימות, על ידי Claude עצמו בזמן אמת.

## מבנה

```
work-patterns-loop/
├── BRIEF.md                        # מה רוצים בסוף + מאיפה מתחילים (אפיון)
├── data/
│   └── raw-patterns.md             # מאגר מרכזי — שורה לכל דפוס, עם ציטוט. Append-only.
└── output/
    └── ai-management-guide.md      # המדריך החי, המאושר — עדכון רק אחרי אישור דניאל
```

## זרימה

1. **תוך כדי שיחה** — "קולט ידע" מזהה דפוס, מציג לדניאל, אם אושר → גם נשמר ככלל/זיכרון כרגיל **וגם** נכתבת שורה ב-`data/raw-patterns.md` (עם ציטוט מדויק מהשיחה).
2. **בכל הפעלה של learning-loop** — גם אוטומטית בסגירת שיחה (`session-close`), וגם כשדניאל מבקש במפורש תוך כדי שיחה ("תלמד מהשיחה", "תתעד אותה", "מה למדנו מזה", "כל הכבוד, בוא נלמד מזה") — בנוסף ללוגיקה הרגילה של learning-loop, בודקים את `raw-patterns.md`: אם דפוס חזר 2+ פעמים באופן עצמאי → מציעים לדניאל עדכון ל-`output/ai-management-guide.md` (עיקרון מנוסח + ציטוט מוכיח).
3. **אם אושר** → המדריך מתעדכן, ו-Claude בודק אם רלוונטי לעדכן את מסמכי הידע של אטלס (`agents/ready/atlas/master-library/`) — מציע, מאשרים, מעדכן, ומזכיר rebuild-plugin.

# מקורות מידע לעסקת נדל"ן — מה עובד ואיך

> נבדק בפועל ב-07/09/2026. כל מה שמסומן ✅ הורץ והחזיר נתונים אמיתיים.
> אם קריאה נכשלת — נסה שוב פעם אחת, ואז עבור למסלול הדפדפן. **אל תמציא נתון.**

---

## 1. העוגן: גוש/חלקה → נקודה ✅

הכול מתחיל כאן. כל מקור אחר צריך או כתובת, או נקודה, או גוש/חלקה.

```bash
curl -s -X POST "https://www.govmap.gov.il/api/search-service/autocomplete" \
  -H "Content-Type: application/json" \
  -d '{"searchText":"6913/17","language":"he","isAccurate":true,"maxResults":3}'
```

מחזיר:
```json
{"results":[{"id":"parcel|LAYER_PARCEL_ALL|267072","text":"גוש 6913 חלקה 17",
 "type":"parcel","shape":"POINT(3870549.078 3772959.118)"}]}
```

- **פורמט החיפוש: `גוש/חלקה` בלבד** — למשל `6913/17`. חיפוש לפי כתובת חופשית
  מחזיר קווי אוטובוס ולא כתובות. **אל תחפש לפי כתובת כאן.**
- הנקודה היא **EPSG:3857** (Web Mercator). שמור אותה — היא המפתח לשלב הבא.
- אם אין לך גוש/חלקה: קח אותו מנסח הטאבו, מדף המידע, או מההיתר. הוא תמיד שם.

## 2. עסקאות השוואה — הנתון הכי חשוב בדוח ✅

### א. מה יש סביב הנקודה

```bash
curl -s "https://www.govmap.gov.il/api/real-estate/deals/{X},{Y}/{radius}"
# דוגמה: .../deals/3870549,3772959/100
```

מחזיר רשימת פוליגונים (בניינים/רחובות) עם `polygon_id` ומספר עסקאות בכל אחד.

- **השתמש ב-X,Y בלי נקודה עשרונית.** עם עשרוניות מקבלים 504.
- רדיוס 100–300 מטר. גדול מזה — timeout.

### ב. העסקאות עצמן

```bash
curl -s "https://www.govmap.gov.il/api/real-estate/street-deals/{polygon_id}"
```

מחזיר לכל עסקה: `dealAmount`, `assetArea`, `assetRoomNum`, `floorNo`, `dealDate`,
`gushNum`, `parcelNum`, `subParcelNum`, `propertyTypeDescription`, `neighborhood`.

**זה הזהב.** מכאן מחשבים ₪/מ"ר אמיתי לפי קומה, גודל וחדרים — ולא ממציאים מחיר.

**כללי שימוש:**
- **סנן לפי תאריך.** עסקה מ-2021 לא רלוונטית ב-2026. קח 18–24 חודשים אחרונים.
- **נרמל לפי קומה.** קומת קרקע ≠ קומה 6. אם יש מספיק דגימות — חשב מקדם קומה.
- **חשד לעסקאות חריגות.** מכירת חלקים, עסקה בין קרובים, דירה מיוחדת. אם ₪/מ"ר
  חורג ביותר מ-30% מהחציון — הוצא אותה או ציין אותה בנפרד.
- **הצג חציון, לא ממוצע.** ממוצע נגרר אחרי חריגה אחת.

## 3. רמ"י — מכרזי קרקע ✅

```bash
curl -s -X POST "https://apps.land.gov.il/MichrazimSite/api/SearchApi/GetMichrazim" \
  -H "Content-Type: application/json" \
  -d '{"StatusMichraz":"","Yeshuv":"","MichrazID":"","PageNumber":1,"PageSize":50}'
```

מחזיר: `MichrazName`, `KodYeshuv`, `YechidotDiur`, `Shchuna`, `PirsumDate`,
`SgiraDate`, `StatusMichraz`, `KodSugMichraz`.

**למה זה חשוב לדוח אפס:** מחירי הזכייה במכרזי רמ"י באזור הם **הבנצ'מרק לשווי
קרקע ליח"ד**. אם החישוב השיורי שלנו נותן ₪1.3M ליח"ד ובמכרז באותה שכונה זכו
ב-₪900K — או שהמחיר המבוקש מנופח, או שאנחנו מפספסים עלות.

שאר האתרים של רמ"י (איתור נכסים, שאילתת מגרש) — **חסומים ל-API. מסלול דפדפן.**

## 4. מנהל התכנון — תוכניות וזכויות 🌐 דפדפן בלבד

`mavat.iplan.gov.il` ו-`ags.iplan.gov.il` חוסמים קריאות ישירות (302/404).
**חייבים דפדפן.**

מה מחפשים ובאיזה סדר:
1. **חיפוש לפי גוש/חלקה** ב-מבא"ת → רשימת תוכניות חלות.
2. לכל תוכנית: **מספר, שם, סטטוס (מאושרת / מופקדת / בהכנה), תאריך.**
3. **הורד את התקנון** — שם יושבים אחוזי הבנייה, מגבלת הקומות, התכסית, מקדם הצפיפות.
4. **התשריט** — קווי בניין וייעודים.

**הסטטוס הוא ההכרעה, לא הזכויות.** תוכנית מופקדת = מצב ב', ומחייבת דחייה
בתחשיב. ראה SKILL שלב 0.

## 5. דף מידע תכנוני / רישוי זמין 🌐 דפדפן או קובץ מהמשתמש

`רישוי זמין` דורש התחברות. **הדרך המהירה: לבקש מנועם את דף המידע כקובץ** —
הוא בדרך כלל כבר בידיו, וזה המסמך הכי צפוף בדוח כולו.

מה שולפים ממנו:
- **שטח לחישוב זכויות** (סעיף 1.1) — לא זהה לשטח בטאבו. השתמש בזה.
- **תוכניות מאושרות מול בתהליך** (1.2.1 / 1.2.2)
- **חבות בהיטל השבחה** (1.3) — אילו תוכניות מחייבות
- **התראות** (1.4) — שימור, גובה, הגבלות
- **הערות מחלקת מידע תכנוני** (1.5) — כאן יושבות ההפתעות: דרישת שטח ציבורי
  מבונה, קיטוע גבולות, 15% שטח פנוי, תקן חניה
- **החלטות ועדה** (3.5) — כללי מרתפים, גזוזטראות, תכסית

## 6. נסח טאבו 🔒 המשתמש מספק

`taboo.justice.gov.il` — דורש תשלום וזיהוי. **אל תנסה לגשת.**
בקש מנועם. בלעדיו אין בעלויות, שעבודים והערות אזהרה — ואלה יכולים להרוג עסקה
אחרי שכל המספרים כבר יצאו יפים.

## 7. מחירי ביקוש (אסמפטה, לא ראיה) 🌐

יד2, מדלן, הומלס — **מחירי בקשה, לא עסקאות.** בישראל הפער בין מבוקש לנסגר הוא
5–12%. שימושי לתקרה ולתמהיל, לא לתחשיב.

**סדר העדיפות בקביעת מחיר מכירה:**
1. עסקאות רשות המסים באותו בניין / באותה חלקה
2. עסקאות באותו רחוב, 18 חודשים אחרונים
3. שומת מקרקעין אם יש
4. מחירי ביקוש בניכוי 8%
5. **אף פעם לא: המצגת של היזם**

## 8. שומת מקרקעין — אם יש, היא גוברת על הכול

אם נועם מצרף שומה (תקן 22, שומה מלאה, שומת בטוחות) — **קרא אותה לפני שאתה
מחשב משהו.** היא נותנת: מחירי מ"ר מנורמלים, שיעורי תשואה, מקדמי קומה,
עלויות הקמה מקצועיות, ותרחישי רגישות שכבר נעשו.

**קריאת PDF של שומה:** קובץ מקומי מעל 10 עמודים נקרא בטווחי עמודים (עד 20 בכל קריאה). אם הקובץ בדרייב —
`read_file_content` עובד. הטקסט חוזר **הפוך תו-אחר-תו** (עברית משוחזרת מ-PDF).
הסקריפט `scratchpad/rev.ps1` הופך שורות בחזרה. גם המספרים הפוכים:
`000,12 ₪` הוא **₪21,000**.

## סיכום: סדר ההרצה

```
1. גוש/חלקה  → GovMap autocomplete   → נקודה
2. נקודה     → deals/{x,y}/200       → polygon_ids
3. polygon_id → street-deals         → עסקאות השוואה  ← ₪/מ"ר אמיתי
4. יישוב     → RMI GetMichrazim      → בנצ'מרק שווי קרקע
5. דפדפן     → מבא"ת                 → תוכניות + סטטוס + זכויות
6. מהמשתמש   → דף מידע, טאבו, גרמושקה, שומה
7. ← עכשיו מתחילים לחשב
```

**כלל אחד מעל הכול:** כל מספר בדוח צריך מקור. מספר בלי מקור נכנס לסעיף
"הנחות שהנחתי", לא לטבלה.

## 9. מקורות נוספים — כדאיים, ורובם לא מובנים מאליהם

### א. מדד תשומות הבנייה — הלמ"ס ✅ נבדק ועובד

```bash
curl -s "https://api.cbs.gov.il/index/data/price?id=200010&format=json&last=12"
```
מחזיר: `מדד מחירי תשומה בבנייה למגורים`. נכון ל-07/2026: **+3.5% שנתי**, ערך 103.5.

**למה זה קריטי:** פרויקט נמשך שנתיים-שלוש. עלות בנייה של ₪10,000/מ"ר היום היא
₪10,700 בעוד שנתיים ב-3.5% לשנה. **בפרויקט של 2,300 מ"ר זה 1.6 מיליון ₪ שנעלמו
מהדוח.** תמיד הצמד את עלות הבנייה למדד לאורך תקופת הביצוע, או לפחות אמור
במפורש שלא הצמדת.

מדדים נוספים באותו API: `120010` מדד המחירים לצרכן, `200011` תשומות סלילה.

### ב. ריבית פריים — בנק ישראל 🌐

ההלוואה על הקרקע היא **פריים + 1.75**. הפריים זז. אל תשתמש ב-3.35% מהתבנית
בלי לבדוק מה הפריים היום — כל 0.5% על הלוואת קרקע של ₪24M הוא ₪120K לשנה.
מקור: אתר בנק ישראל, או חיפוש רשת.

### ג. תמ"א 70 / מטרו — **הפתעה שמשנה זכויות** 🌐

בשני המסמכים שראינו זה הופיע והשפיע:
- באידלסון-הס: תמ"א 70 מופיעה כ**התראה** בדף המידע.
- בדרום השרון: *"הנכס נכלל בתחום העצמת זכויות בגין תמ"א 70"* — כלומר **תוספת**
  זכויות, וזה חלק מרכזי מהשווי.

**תמ"א 70 יכולה גם להעניק וגם להגביל.** בדוק תמיד את המרחק לתחנת מטרו מתוכננת
ואת המרחב הרובעי. שכבות ב-GovMap ובמנהל התכנון.

### ד. היטלי פיתוח ואגרות — אתר הרשות המקומית 🌐

ברירת המחדל בתבנית היא ₪300/מ"ר ל"אגרות רישוי ומים". **זה מספר גס.**
היטלי סלילה, ביוב, תיעול ושצ"פ נקבעים **בחוקי עזר עירוניים** ומשתנים פי שניים
ויותר בין רשויות. באתר כל עירייה יש טבלת תעריפים. לפרויקט מעל 10 יח"ד — שווה
לבדוק בפועל.

### ה. פיקוד העורף — תקן ממ"ד 🌐

גודל הממ"ד נכנס לשטח השירות ולעלות. שינויי תקן משפיעים ישירות על יחס
עיקרי/שירות. רלוונטי במיוחד אחרי 2024–2026.

### ו. מחשבוני רשות המסים 🌐

מס רכישה (6% בתבנית הוא שיעור לקרקע/דירה נוספת — **לא אחיד**), מס שבח, ומע"מ.
בעסקת קומבינציה או קבוצת רכישה המבנה שונה לגמרי. **אם העסקה אינה רכישה פשוטה
של קרקע — אל תשתמש ב-6% אוטומטית.**

### ז. data.gov.il ✅ עובד

```bash
curl -s "https://data.gov.il/api/3/action/package_search?q=<נושא>&rows=5"
```
מאגר ה-CKAN הממשלתי. יש שם היתרי בנייה, אזורי עדיפות לאומית, נתוני רשויות.
שימושי כשצריך נתון שאין ב-GovMap.

### ח. מדד מחירי דירות — הלמ"ס

לצורך **הצמדת מחירי המכירה קדימה**. אם הפרויקט נמכר בעוד שנתיים, מחיר היום הוא
לא מחיר המכירה. אבל **זהירות: הצמדת הכנסות קדימה היא הנחה אופטימית.** אם הצמדת
את ההכנסות — חובה להצמיד גם את העלויות, ולהציג גם תרחיש בלי הצמדה בכלל.

# שחזור ידני — דוח אפס בלי הסקיל

לשימוש כשהסקיל לא נטען, או כשעובדים בכלי אחר.
9 צעדים. כל צעד = פעולה אחת שאפשר לבצע.

---

**1. קבע איזו עסקה זו — וסמן את מצב התכנון.**
יזמי (בונים ומוכרים) או מניב (משכירים)? אם מניב — עצור, זו שיטה אחרת (היוון הכנסות).
ואז: התב"ע **מאושרת** או **מופקדת**? מופקדת = חייבים שני מספרים, לא אחד.

**2. השג את הגוש/החלקה, וממנו את הנקודה.**
```
POST https://www.govmap.gov.il/api/search-service/autocomplete
{"searchText":"6913/17","language":"he","isAccurate":true,"maxResults":3}
```
חפש בפורמט `גוש/חלקה` בלבד. שמור את ה-`POINT(x y)`.

**3. משוך עסקאות השוואה.**
```
GET /api/real-estate/deals/{x},{y}/200        → polygon_ids   (בלי עשרוניות!)
GET /api/real-estate/street-deals/{id}        → העסקאות עצמן
```
סנן ל-18 חודשים אחרונים. חשב **חציון ₪/מ"ר**, לא ממוצע. זה מחיר המכירה שלך.

**4. פרק את המטרים לארבע שכבות.**
עיקרי / שירות עילי / מרפסות / מרתף+חניון.
שירות = 20% מהעיקרי. חניה = 35 מ"ר. **שירות נבנה ולא נמכר. מרפסת נמכרת בחצי.**

**5. בנה את טבלת ההכנסות.**
שורה לטיפוס: `מחיר = ₪/מ"ר × (שטח + מרפסת÷2)`. מחיר שונה לדירת גן ולפנטהאוז.
**חלק את סך ההכנסות ב-1.18** להורדת מע"מ.

**6. בנה את טבלת ההוצאות.**
קרקע, תיווך 2%, מס רכישה 6%, **היטל השבחה**, בנייה ₪10,000/מ"ר, מרתף וחניון
₪6,000, מרפסות ₪2,000, פיתוח ₪250/מ"ר מגרש, ואז העקיפות.
**חשב את העקיפות פעמיים: 12.5% ו-30%. הצג את שתיהן.**

**7. חשב מימון בטבלה נפרדת — והוסף את הסכום לשורת ההוצאות.**
ריבית קרקע פריים+1.75, ליווי 0.75%, ערבויות חוק מכר ~1.35%×שנים, מפקח פיננסי.
**זה השלב שהכי נשכח. בלעדיו הדוח שגוי במיליונים.**

**8. חשב שלושה מספרי רווחיות.**
רווח (הכנסות−הוצאות) · רווחיות על העלות (רווח÷הוצאות) · **תשואה שנתית על ההון**
(רווח ÷ הון עצמי ÷ שנים). הון עצמי = 35% מהקרקע **+** 18% מסך ההוצאות.

**9. הרץ את בדיקת השפיות וכתוב את "מה חסר".**
מרפסות עקביות? מספרים שנשארו מהתבנית? מע"מ ירד? מימון חזר? השבחה נאמדה?
זכויות שלא ניתן לנצל? ואז רגישות: מחיר −10%, עלות +10%, תקופה +שנה.
**דוח בלי החלק הזה אינו דוח אפס.**
